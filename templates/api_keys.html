{{ icon("info") }} About API Keys

All API keys are read-only — they can query leases, devices, reservations, and subnet stats but cannot make any changes to your network.

Keys are passed in the Authorization: Bearer <key> HTTP header.

A key is shown only once at creation time. If you lose it, revoke it and generate a new one. {% if current_user.role != 'superadmin' %}

You can see and manage only the API keys you've created yourself. A superadmin can see and manage every key.{% endif %}
