About Plugins

Plugins add optional capabilities to Jen without bloating the core install. Each plugin is a self-contained package with its own routes, templates, and database tables.

Installed plugins live in /opt/jen/plugins/. Enabling or disabling a plugin requires a Jen restart to take effect.

Want to build a plugin? See the plugin developer guide on GitHub.
