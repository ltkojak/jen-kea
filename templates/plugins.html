About Plugins

Plugins are optional add-ins that extend Jen without touching the core install. Each has its own routes, templates, and database tables. Your data is preserved when a plugin is uninstalled — only the plugin files are removed.

{% if is_systemd_host %} A newly installed plugin is fetched and verified by a dedicated root-privileged service and lands read-only under /opt/jen/plugins-installed/ — the running Jen process itself can never write there. A plugin marked "writable" was installed before this existed; use Reinstall to move it there. {% else %} Installed plugins live in /opt/jen/plugins/. {% endif %} Enable/disable changes take effect after restarting Jen.

Want to build a plugin? See the plugin developer guide on GitHub.
