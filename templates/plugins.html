About Plugins

Plugins are optional add-ins that extend Jen without touching the core install. Each has its own routes, templates, and database tables. When a plugin is uninstalled only its files are removed: its database tables and data are kept in the database and in every backup, and shown again when the plugin is reinstalled.

{% if is_systemd_host %} A newly installed plugin is fetched and verified by a dedicated root-privileged service and lands read-only under {{ jen_layout.plugin_dir_root }}/ — the running Jen process itself can never write there. A plugin marked "writable" was installed before this existed; use Reinstall to move it there. {% else %} Installed plugins live in {{ jen_layout.plugin_dir }}/. {% endif %} Enable/disable changes take effect after restarting Jen.

Want to build a plugin? See the plugin developer guide on GitHub.
