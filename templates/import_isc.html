📄 Import from ISC DHCP

Migrate subnets, reservations and classes from an ISC dhcpd.conf.

Step 1 — Upload dhcpd.conf

Copy /etc/dhcp/dhcpd.conf from the ISC DHCP server (and, if it uses include, paste the included files into it first — includes are not followed). Optionally add /var/lib/dhcp/dhcpd.leases: it is read only to tell you how many active leases sit in the ranges you are about to import, never imported.

IPv4 (dhcpd.conf), up to 5 MB. A dhcpd6.conf is not imported.
Only counted on the review page. Kea starts with an empty lease database.
ℹ️ Nothing is written to Kea at upload. The review step lists every subnet, reservation and class Jen would create — and every directive it cannot map, with its line number — then Preview runs kea-dhcp4 -t and shows a diff before anything changes. This only ever touches the primary Kea server's config; an HA partner gets it the way you already sync config.
⚠️ What maps: global and per-subnet options, default-lease-time, subnet/range (several ranges become several pools), shared-network, host reservations (hardware ethernet + fixed-address), class … match if on vendor/user class, hostname, MAC/OUI, client id and relay ids, pool allow/deny members of, next-server and filename. Not mapped, and listed as warnings: option definitions, include, failover, if/elsif, subclass, spawn, OMAPI and DDNS keys/zones.
