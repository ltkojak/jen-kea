🪟 Import from Windows DHCP

Migrate scopes, reservations, and policies from a Windows DHCP server export.

Step 1 — Upload the export

On the Windows DHCP server, run: 

Export-DhcpServer -ComputerName <server> -Leases:$False -File C:\dhcp-export.xml

Upload that XML file below. Nothing is written to Kea yet — the next step shows exactly what would be created before anything changes.

The raw XML from Export-DhcpServer, up to 5 MB.
ℹ️ This only ever touches the primary Kea server's config. If you run an HA pair, sync the change to the partner the same way you already do for any other config edit.
