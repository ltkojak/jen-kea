{{ icon("book-open") }} About
The Kea DHCP Management Console

A full-featured web management interface for ISC Kea DHCP Server, built for homelab and small infrastructure deployments. It sits alongside ISC's Stork rather than replacing it; the README compares the two.

Jen provides lease management, static reservations, subnet editing, multi-channel alerts, audit logging, and more — all from a browser-based UI.
