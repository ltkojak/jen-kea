{{ icon("box") }} Recovery bundle — contains secrets

One encrypted file to stand Jen back up on a new machine: jen.config, the MFA encryption key, TLS/SSH keys, a fresh export of every Jen database table, uploaded content (icons, branding), and the latest Kea config Jen has seen for each server.

{{ icon("triangle-alert") }} This bundle is NOT redacted — unlike the support bundle, it contains real secrets (database credentials, the MFA key, private keys) so the restore actually works. It is only as secret as the passphrase you choose below; anyone with both the file and the passphrase can decrypt everything in it. Store it somewhere only you control, and never send the passphrase alongside the file. For a file to attach to a bug report, use the redacted support bundle (Settings → System) instead.
Write this passphrase down somewhere safe — Jen never stores it, and there is no recovery if you lose it.
To restore onto a new machine, run sudo ./install.sh --restore /path/to/bundle.tar.enc — see the admin guide's "Recover Jen on a new machine" runbook for the full walkthrough.
